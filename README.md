# Google検索だけDuckDuckGoへ (Chrome拡張)

新しいタブと既定の検索エンジンは **Googleのまま**。
Googleで検索を実行したときだけ、同じ検索ワードで **DuckDuckGo** にリダイレクトします。

## 仕組み
- 新しいタブ・既定の検索エンジン設定は一切変更しません。
  （新しいタブはGoogle標準の検索ボックス・ロゴ・タイルがそのまま使えます）
- `declarativeNetRequest` で `https://www.google.com/search?q=...` のような
  「検索結果ページへの遷移」だけを検知し、`https://duckduckgo.com/?q=...` に
  クエリ付きで差し替えます（`google.co.jp` など各国ドメインにも対応）。
- アドレスバー検索・新しいタブの検索ボックス・Google検索のどれを使っても、
  検索を実行した瞬間にDuckDuckGoへ飛びます。

## アドレスバーの表示について
アドレスバーの「Google で検索…」という表示は既定の検索エンジンと
連動しているため、新しいタブをGoogle標準のまま残すこの構成では
そのまま「Google で検索…」になります（検索結果はDDGに飛びます）。

## インストール方法（パッケージ化されていない拡張機能の読み込み）
1. Chromeで `chrome://extensions` を開く
2. 右上の「**デベロッパー モード**」をオン
3. 「**パッケージ化されていない拡張機能を読み込む**」をクリック
4. このフォルダ（`manifest.json` がある場所）を選択

## 既定の検索エンジンをGoogleに戻す（前バージョンを使っていた場合）
以前のバージョンで既定をDuckDuckGoに変更していた場合は、
`chrome://settings/searchEngines` を開き、既定の検索エンジンを
**Google** に選び直してください。

## 無効化・元に戻す
`chrome://extensions` でこの拡張をオフにすれば、すぐにGoogle検索に戻ります。
